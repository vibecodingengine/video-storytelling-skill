# 通用视频叙事 Skill

让 Codex 根据真实素材完成：**找素材 → 分析 → 提出剪辑方案 → 确认旁白 → 配音试音 → 审阅粗剪 → 定稿**。

不绑定任何国家、语言或个人身份。原声语言、旁白语言、字幕语言和聊天语言分别选择；可以不加旁白，也可以使用有许可的预设音色或经过授权的克隆声音。

## 安装和使用

可以直接对 Codex 说：

> 用 $skill-installer 从 https://github.com/vibecodingengine/video-storytelling-skill 安装 skills/video-storytelling。

手动安装时，将 `skills/video-storytelling` 复制到用户级目录 `~/.agents/skills/video-storytelling`，或项目内的 `.agents/skills/video-storytelling`。保留 `SKILL.md` 和 `references/`，不要把整个仓库当成 skill 文件夹复制。已有同名安装时先保留旧版。这些是使用者自己的相对目录，不是作者本机路径；不同版本的发现位置以[官方文档](https://learn.chatgpt.com/docs/build-skills)为准。安装后未出现时重启 Codex。

首次使用可先说：

> 用 $video-storytelling 检查可用工具，并读取它自带的参考文件。暂时不要剪辑或上传任何内容。

它应核对素材访问、媒体探测与渲染、画面和音频检查，以及按需使用的转写或配音引擎。缺少工具时应提出具体配置或替代方案；没有 Photos 访问能力时使用导出的本地文件。此检查用于确认运行条件，不等同于完整成片测试。

示例：

> 用 $video-storytelling 找我指定的旅行相册里的素材，先分析，再提一个两分钟剪辑方案。旁白用中文，字幕语言我们再确定。先让我确认完整旁白，再试听一个普通音色，确认后继续剪。

## 四个关键确认点

1. **剪辑方案**：故事结构、素材选择、时长和画幅。
2. **完整旁白**：确认具体版本后才生成完整配音、制作旁白驱动的剪辑。
3. **配音试听**：确认音色和语速；已明确认可的配置可复用。
4. **粗剪与字幕**：确认内容后再制作定稿。

已确认且未改动的内容不反复询问；有实质修改的旁白和翻译需要重新确认对应版本。

## iCloud 和工具能力

支持本地目录，以及具备访问条件时的 iCloud Drive、iCloud 照片流程。二者不能混为一谈：照片图库需要可用的 Photos 访问或正常导出；云端占位文件必须下载完成后才能分析。

这是工作流说明，不自带 iCloud 爬虫、视频剪辑程序或配音引擎。执行环境需要 FFmpeg/ffprobe 等媒体工具；转写和配音根据项目选择可用引擎。不强制付费 API，不依赖作者的私人 skill。

## 隐私

公开仓库只存通用说明。素材、相册信息、定位、真实本机路径、转写稿、个人项目记录、声音样本、声纹和密钥保存在仓库外。调用云服务处理私人内容前，需要有相应授权；从网上选择声音是选择有许可的音色，不是随意抓取别人的声音克隆。

不会自动发布视频、清理原片或迁移个人归档。本仓库不包含第三方剪辑脚本、模型权重或个人示例媒体。贡献示例请使用虚构素材信息。

通用说明采用 MIT 许可；实际使用的工具、模型、声音和配乐遵循各自许可。
